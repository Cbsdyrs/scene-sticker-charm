把这个文件夹里的 index.html 上传到 GitHub，替换旧的同名文件。

步骤：
1. 打开 https://github.com/Cbsdyrs/scene-sticker-charm
2. 点右上角 Add file（添加文件）→ Upload files（上传文件）
3. 把本文件夹里的 index.html 拖进上传框（文件名必须是 index.html，才会替换旧文件）
4. 页面拉到底，点绿色按钮 Commit changes（提交更改）
5. 等约 1 分钟，然后按 Ctrl + Shift + R 强制刷新网页

链接不变：https://cbsdyrs.github.io/scene-sticker-charm/

如果上传后仓库里出现了两个 html 文件（index.html 和别的名字），请把多余的那个删掉，
否则网页可能仍然显示旧版本。
